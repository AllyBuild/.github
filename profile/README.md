## What We're Building

AllyBuild is an AI agent collaboration platform: task scheduling, execution, and
skill evolution inside securely isolated sandboxes — so AI agents keep working
and growing inside your real projects.

- **🤖 Script & Agent dual execution** — deterministic scripts (Python / TypeScript)
  and autonomous agent tasks cooperate in the same pipeline
- **sandbox isolated execution** — every project runs in its own cloud sandbox;
  each agent step is controlled and auditable
- **🔗 Full GitLab integration** — tasks automatically branch, commit, push,
  and open Merge Requests
- **📈 Self-evolving skills** — agents distill reusable skills from real tasks
  and get better with use
- **🌍 Open-source community** — browse and fork open-source projects and
  templates, and let good engineering practices flow
